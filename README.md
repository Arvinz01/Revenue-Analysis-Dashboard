# Customer & Revenue Analysis Dashboard | Power BI

## Project Overview
This project focuses on analysing customer information, revenue performance and purchasing behaviour using Microsoft Power BI. The dashboard provides insights into customer revenue, order patterns, income groups and customer segmentation through interactive data visualisations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualisation

## Dashboard Features

### 1. Customer Overview
- Total number of customers
- Revenue per customer
- Customer analysis over time

### 2. Revenue Analysis
- Total revenue generated by customers
- Top customer by revenue
- Revenue per customer analysis

### 3. Order Analysis
- Total orders
- Top customer by order volume
- Orders segmented by customer income group
- Orders by occupation

### 4. Customer Details
- Customer ID
- Customer full name
- Total revenue
- Total orders

## Key Skills Demonstrated
- Data Analysis
- Data Modelling
- Data Visualisation
- DAX Measures
- Business Intelligence
- Customer Segmentation
- Dashboard Development

## Project File
`Revenue analysis dashboard.pbix`

Open the PBIX file using Microsoft Power BI Desktop to explore the dashboard and its visualisations.

## Objective
To transform customer data into meaningful business insights that support understanding of customer purchasing behaviour, revenue contribution and customer performance.
